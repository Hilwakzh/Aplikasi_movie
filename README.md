🎬 HilwaFlix

HilwaFlix is a movie discovery application developed using Flutter and Dart. Inspired by the Netflix interface, this application provides a modern dark-themed design for browsing and discovering movies.

✨ Features

Featured Movie Banner — Displays a featured movie on the home screen.

Movie Categories — Browse movies by categories such as Trending Now, Popular on HilwaFlix, and Action & Adventure.

Movie Search — Search for movies by title.

Movie Details — View movie information through a detail dialog.

My List — Add or remove movies from a personal favorites list.

Dark Theme UI — A dark interface inspired by popular streaming platforms.

Responsive Movie Layout — Horizontal movie lists for convenient browsing.

## 🛠️ Technologies Used

- **Flutter** — Framework for building the application UI.
- **Dart** — Programming language used for development.
- **Android Studio** — Used to create and run the Android emulator.
- **Visual Studio Code** — Used to write and edit the source code.
- **Material Design** — UI design system for Flutter widgets.

## 🚀 Prerequisites

Before running HilwaFlix, make sure you have installed:

- Flutter SDK
- Dart SDK
- Visual Studio Code
- Android Studio with an Android Virtual Device (AVD)
- Android SDK and required emulator components

## ▶️ Running the Application

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Start an Android emulator through **Android Studio → Device Manager**.

5. Run the application in the VS Code terminal:

   ```bash
   flutter run
   ```

   To select a specific emulator, use:

   ```bash
   flutter run -d emulator-5554
   ```

   📌 Project Status

This project currently focuses on the user interface and basic movie discovery interactions. Movie data is defined in the application code. The Play button is a demonstration feature and does not stream movies. The My List feature currently stores selections in memory while the application is running.
